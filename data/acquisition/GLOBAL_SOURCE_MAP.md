# SENTRA-FS Global Food Import Source Map

## 1. India

### Primary Source: FSSAI Food Import Clearance System (FICS) / Non-Conformance Reports (NCR)
- **Official Organization:** Food Safety and Standards Authority of India (FSSAI), Ministry of Health and Family Welfare.
- **Dataset / Portal Name:** FICS (Food Import Clearance System) / FIRA (Food Import Rejection Alerts) / Non-Conformance & Rejection Notices.
- **What the Data Actually Represents:** Consignment-level border rejection records where imported food shipments failed visual inspection, document scrutiny, or mandatory laboratory testing at Indian Ports of Entry.
- **Food-Import Relevance:** 100% dedicated to imported food consignments subject to the Food Safety and Standards (Import) Regulations.
- **Refusals / Rejections / Border Controls Represented:** Yes. Each record represents an official Non-Conformance Report (NCR) or Rejection Order leading to denial of clearance or re-export/destruction order.
- **Supplements / Nutraceuticals Represented:** Yes, specifically regulated under FSSAI's Food Safety and Standards (Health Supplements, Nutraceuticals, Food for Special Dietary Use, Food for Special Medical Purpose, and Prebiotic and Probiotic Food) Regulations.
- **Date Coverage:** Active live transactional database; periodic public disclosure lists and annual bulletins span 2016–Present (irregular publishing cadence).
- **Available Fields:** Consignment / Bill of Entry details, Port of Entry (e.g., JNPT, Chennai, Nhava Sheva, Delhi Air Cargo), Country of Origin, Product Category / Sub-category, Importer Name, Declared Commodity Description, Parameter Failed (e.g., heavy metals, aflatoxins, pesticide residues, labeling non-conformance), Reason for Rejection.
- **Download Method:** Semi-manual / Portal extraction. Rejection notices and periodic non-conformance summaries are published as tabular PDF notifications or dynamic listings on the FSSAI portal.
- **API Availability:** No public REST/JSON API. FICS transactional API is restricted to authorized Customs Icegate brokers, authorized officers, and accredited referral labs.
- **CSV / JSON / XML Availability:** Not natively published as bulk CSV/JSON. Distributed primarily as structured tabular PDFs or HTML tables.
- **Whether Historical Data Is Accessible:** Partially. Historical bulletins are retained in the FSSAI document archive, but transactional databases are not exposed in historical bulk CSV format.
- **Whether Authentication Is Required:** Public rejection bulletins do not require authentication; transactional daily consignment queries require customs broker / departmental login.
- **Whether Automated Acquisition Appears Technically Feasible:** Medium. Automated web scrapers can monitor and extract public PDF bulletins and HTML tables using tools like `pdfplumber` and `BeautifulSoup`. Full transactional bulk feeds require departmental data access.
- **Official URL:** `https://www.fssai.gov.in/` and `https://fics.fssai.gov.in/`
- **Important Limitations:** Fragmented publishing across monthly/annual PDF reports; absence of a consolidated static bulk CSV file; observed laboratory quantitative values (exact numerical reading vs limit) are inconsistently detailed across different reporting years.
- **Estimated Usefulness to SENTRA-FS:** **HIGH** (Anchor source for domestic mandate).

## 2. European Union

### Primary Source: Rapid Alert System for Food and Feed (RASFF) / iRASFF
- **Official Organization:** European Commission, Directorate-General for Health and Food Safety (DG SANTE).
- **Dataset / Portal Name:** RASFF Window / Safety Gate (iRASFF Portal).
- **What the Data Actually Represents:** Official border rejection notifications, information notifications, and border control alerts generated by EU Member State border inspection posts (BIPs) when consignments entering the European Economic Area (EEA) violate EU food safety regulations.
- **Food-Import Relevance:** 100% food and feed. Filterable strictly to human food.
- **Refusals / Rejections / Border Controls Represented:** Yes. Specifically categorizes notifications by `Border Rejection`, `Alert Notification`, and `Information Notification for Attention/Follow-up`.
- **Supplements / Nutraceuticals Represented:** Yes, categorized under `Dietetic foods, food supplements and fortified foods`.
- **Date Coverage:** 1979–Present (Daily / weekly updates; comprehensive digital records from 2000 onward).
- **Available Fields:** Reference Number, Notification Date, Notification Type (e.g., Border Rejection), Notification Basis, Country of Origin, Notifying Country, Product Category, Hazard Category, Hazard / Analytical Parameter (e.g., Ochratoxin A, Chlorpyrifos), Observed Value / Analytical Result, Regulatory Limit / Maximum Residue Limit (MRL), Units of Measurement, Action Taken (e.g., re-dispatch, destruction, detention), Risk Decision.
- **Download Method:** Automated API / Direct Query Export (CSV/Excel via the iRASFF web consumer API).
- **API Availability:** Yes. The RASFF Window portal utilizes an underlying public REST JSON API endpoint (`https://ec.europa.eu/food/safety/rasff-window/backend/api/consumers/...`) querying public records with filtering parameters.
- **CSV / JSON / XML Availability:** Yes. Underlying API provides structured JSON; portal front-end allows CSV/Excel bulk exports.
- **Whether Historical Data Is Accessible:** Yes. Full multi-decade historical archive is accessible via query pagination.
- **Whether Authentication Is Required:** No authentication or API token required for public queries.
- **Whether Automated Acquisition Appears Technically Feasible:** High. Structured HTTP `GET`/`POST` requests can paginate the REST API to retrieve records as clean JSON.
- **Official URL:** `https://ec.europa.eu/food/safety/rasff-window/screen/search`
- **Important Limitations:** Does not report customs entry numbers, commercial invoice costs, or full private commercial consignee details due to EU GDPR and commercial confidentiality rules.
- **Estimated Usefulness to SENTRA-FS:** **HIGH** (The gold standard for multi-jurisdiction border rejection and parameter-level failure intelligence).

## 3. United Kingdom

### Primary Source: UK Food Standards Agency (FSA) Alerts & Border Rejection Notifications
- **Official Organization:** Food Standards Agency (FSA) / Food Standards Scotland (FSS).
- **Dataset / Portal Name:** FSA Food Alerts / Port Health Authority Border Notifications.
- **What the Data Actually Represents:** Food border non-compliance notices, border control alerts, and food hazard notifications generated by UK Border Control Posts (BCPs) post-Brexit (replacing direct UK RASFF integration).
- **Food-Import Relevance:** Direct food and feed relevance. Covers imported foods arriving from non-EU countries and EU entries subject to the UK Border Target Operating Model (BTOM).
- **Refusals / Rejections / Border Controls Represented:** Yes. Reports border rejections and non-compliant import interventions.
- **Supplements / Nutraceuticals Represented:** Yes, recorded under specialized food categories and dietary additions.
- **Date Coverage:** 2021–Present (distinct UK national data post-Brexit transition; earlier UK historical rejections are embedded within EU RASFF 1979–2020).
- **Available Fields:** Reference ID, Publication Date, Product Title/Description, Country of Origin, Contaminant / Risk Cause, Action Taken at Port, Notifying Port Health Authority (PHA).
- **Download Method:** REST API query / RSS feed / Open Data CKAN endpoints.
- **API Availability:** Yes. Accessible via `https://data.food.gov.uk/food-alerts/` API.
- **CSV / JSON / XML Availability:** JSON and XML are natively supported via open REST endpoints.
- **Whether Historical Data Is Accessible:** Yes, covering the active post-Brexit period (2021–Present).
- **Whether Authentication Is Required:** No. Freely accessible open public data.
- **Whether Automated Acquisition Appears Technically Feasible:** High. Standard RESTful JSON interface with clear parameter documentation.
- **Official URL:** `https://data.food.gov.uk/food-alerts/` and `https://www.food.gov.uk/news-alerts/alerts`
- **Important Limitations:** Post-Brexit volume is smaller than the EU-wide dataset; some low-risk border rejections handled by individual Port Health Authorities are published via local municipal reports rather than immediate centralized national API feeds.
- **Estimated Usefulness to SENTRA-FS:** **MEDIUM** (Valuable comparative benchmark for Western European import controls outside the EU framework).

## 4. Russia

### Primary Source: Rosselkhoznadzor (Federal Service for Veterinary and Phytosanitary Surveillance)
- **Official Organization:** Federal Service for Veterinary and Phytosanitary Surveillance (Rosselkhoznadzor), Ministry of Agriculture of the Russian Federation.
- **Dataset / Portal Name:** Information System "Argus" / Register of Temporary Restrictions and Enhanced Laboratory Control on Imported Products.
- **What the Data Actually Represents:** Border control inspection decisions, notifications of temporary import restrictions, refusals of entry at Russian customs borders, and mandatory notifications of consignments failing EAEU (Eurasian Economic Union) Technical Regulations.
- **Food-Import Relevance:** High for agricultural products, fish, meat, dairy, fruits, vegetables, and grain imports.
- **Refusals / Rejections / Border Controls Represented:** Yes. Specifically documents non-compliant foreign enterprises, rejected consignments, and consignments placed under "enhanced laboratory control" due to sanitary/phytosanitary violations.
- **Supplements / Nutraceuticals Represented:** Minimal in Rosselkhoznadzor. Dietary supplements and specialized food products in Russia fall under **Rospotrebnadzor** (Federal Service for Surveillance on Consumer Rights Protection and Human Wellbeing) via the Unified Register of State Registration Certificates.
- **Date Coverage:** 2008–Present (active updates).
- **Available Fields:** Enterprise Name, Enterprise Approval Number, Country of Origin, Product Type / Commodity Group, Type of Restriction (Refusal, Temporary Restriction, Enhanced Lab Control), Date of Decision, Reason / Parameter (e.g., Salmonella, Listeria, pesticide exceedance, quarantine pests, heavy metals).
- **Download Method:** HTML table scraping / Portal search queries.
- **API Availability:** No publicly documented external REST API for third-party automated consumption.
- **CSV / JSON / XML Availability:** Not provided as standard downloadable CSV/JSON bulk datasets. Published as searchable web registries and official directive documents (PDF/HTML).
- **Whether Historical Data Is Accessible:** Yes, archived on the official portal by enterprise and country.
- **Whether Authentication Is Required:** No for reading the public registry; internal "Argus" transaction system requires departmental/customs credentials.
- **Whether Automated Acquisition Appears Technically Feasible:** Low to Medium. Web structure requires parsing Russian-language HTML tables and directives. Potential geopolitical connectivity and IP routing constraints.
- **Official URL:** `https://fsvps.gov.ru/` (Rosselkhoznadzor) and `https://www.rospotrebnadzor.ru/` (Rospotrebnadzor).
- **Important Limitations:** Russian language only (Cyrillic scripts, requiring transliteration and specialized entity resolution); split jurisdiction between two agencies (Rosselkhoznadzor for raw agri/meat/fish/produce, Rospotrebnadzor for packaged foods/supplements); lack of standard REST endpoints or bulk CSV downloads.
- **Estimated Usefulness to SENTRA-FS:** **LOW to MEDIUM** (P2 candidate: valuable for Eurasian trade corridors, but high technical friction for initial MVP).

## 5. Other Candidates

### A. Japan: Ministry of Health, Labour and Welfare (MHLW)
- **Official Organization:** Ministry of Health, Labour and Welfare (MHLW), Department of Food Safety.
- **Dataset / Portal Name:** Imported Foods Inspection Services — Cases of Violation of the Food Sanitation Act.
- **What the Data Actually Represents:** Explicit monthly and annual official border rejection logs detailing imported food shipments that violated the Japanese Food Sanitation Act at Quarantine Stations.
- **Food-Import Relevance:** 100% dedicated to food imports.
- **Refusals / Rejections Represented:** Yes. Every record is an explicit border violation and rejection.
- **Supplements Represented:** Yes, included under processed food formulations.
- **Date Coverage:** 2004–Present (published in monthly batches).
- **Available Fields:** Notification Date, Port Quarantine Station, Country of Origin, Product Name / Description, Importer Name, Foreign Manufacturer / Processing Plant, Substance / Parameter Failed (e.g., unauthorized food additive, aflatoxin, residual agricultural chemical, bacterial count), Quantitative Measured Value, Regulatory Standard / Limit, Action Taken (Disposed / Returned / Re-exported).
- **Format & Acquisition:** Static Excel (`.xls` / `.xlsx`) and HTML tables published monthly on static directory pages. Highly feasible programmatic download.
- **Usefulness:** **HIGH** (Contains exact numerical measured values and regulatory limits).

### B. Australia: Department of Agriculture, Fisheries and Forestry (DAFF)
- **Official Organization:** DAFF (Commonwealth of Australia).
- **Dataset / Portal Name:** Imported Food Inspection Scheme (IFIS) — Failing Food Reports.
- **What the Data Actually Represents:** Official monthly records of imported food consignments that failed analytical compliance testing or inspection under the Imported Food Control Act 1992.
- **Food-Import Relevance:** 100% imported food.
- **Refusals / Rejections Represented:** Yes (failed tests leading to holding orders, destruction, or re-export).
- **Supplements Represented:** Limited (therapeutic goods/supplements are regulated separately by the TGA).
- **Date Coverage:** 2008–Present (Monthly reports).
- **Available Fields:** Month/Year, Country of Origin, Producer Name, Food Description, Test Applied (e.g., E. coli, Histamine, Lead, Labeling), Analytical Test Result, Action.
- **Format & Acquisition:** HTML tables and downloadable PDFs.
- **Usefulness:** **HIGH** (Structured monthly inspection failure tables with explicit producer names and failure reasons).

## 6. Recommended Acquisition Priority

| Rank | Jurisdiction / Source | Primary Justification |
|---|---|---|
| **1** | **European Union (RASFF)** | **Highest Immediate Value & Technical Feasibility.** Fully accessible public REST API; comprehensive 1979–Present archive; explicit observed laboratory measurements, regulatory limits, and units of measurement. Provides the exact parameter-level quantitative depth that the US FDA refusal dataset lacks. |
| **2** | **India (FSSAI FICS / FIRA)** | **Core Project Mandate.** Non-negotiable domestic anchor for the platform. Acquisition requires targeted PDF tabular parsing or web scrapers to assemble the historical baseline, but it establishes the primary national intelligence framework. |
| **3** | **Japan (MHLW Imported Food Violations)** | **Data Quality Leader.** Monthly Excel tables with complete parameter failure data, producer identities, exact numeric observed concentrations, and statutory limits. Zero API friction—direct static spreadsheet downloads. |
| **4** | **Australia (DAFF IFIS Failing Foods)** | **High Quality Western Benchmark.** Structured monthly records covering border inspection lab failures, clear product categories, and explicit test failure reasons with simple HTML scraping. |
| **5** | **United Kingdom (FSA Alerts)** | **Modern Open Data API.** Clean JSON REST endpoints, but covers a smaller post-Brexit volume and fewer raw border rejections compared to EU RASFF. |
| **6** | **Russia (Rosselkhoznadzor / Rospotrebnadzor)** | **Deferred to Phase 2.** Significant technical complexity (bilingual transliteration, split agency jurisdictions, lack of bulk CSV/API formats, web layout fragility). |
